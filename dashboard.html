Dashboard Guide

Data Source

The dashboard reads all sheets/tabs from the input Excel file. Records from every sheet are merged into a single dataset. Each record tracks which sheet it originated from.

Event Types

  • PO (Purchase Order): Adds to the project budget.
  • Working Time: A fee. Calculated as hours × billing rate × (1 + surcharge rate). The billable amount is shown instead of the Amount field.
  • Purchase: A direct expense (e.g. software licenses, hardware).
  • T&L: Travel & Logistics expenses.
  • Invoice: Invoiced amounts. Informational only — not a charge, not added to the budget. Used for the Invoice Balance calculation.
  • Deferment: Positive deferment adds to the budget and counts as invoiced. Negative deferment reduces the budget. Not included in charges.
  • Financial Record: Positive amounts are used in the Coverage calculation (Charges / (Invoiced + Positive Financial Record)) but are not counted as invoiced. Negative amounts reduce the budget. Not included in charges.
  • Closure: Marks the project end date. The budget forecast extends to the closure month.

Summary Cards

Charges/Invoiced: Ratio of total invoices to total charges, expressed as a percentage.

Total Projects: Number of unique projects in the dataset.

Project Status: Number of projects in each forecast status — green (positive), yellow (slightly negative), red (significantly negative).

Budget: Total Purchase Order coverage across all projects (includes positive Deferment and is reduced by negative Deferment and negative Financial Records).

Total Charges: Sum of Working Time fees + Purchase expenses + T&L expenses. Deferment and Financial Record are not charges.

Total Invoices: Total invoiced amounts (includes Invoice events and positive Deferment). Positive Financial Records are not counted as invoiced.

Invoice Balance: (Invoiced + Positive Financial Record) minus Total Charges. Negative (red) = underinvoiced; positive = overinvoiced.

Remaining Budget: Budget minus Total Charges.

Coverage: Shown next to each project name. Calculated as Total Charges / (Invoiced + Positive Financial Record). This ratio indicates how much of the invoiced-or-planned amount has actually been charged. Positive Financial Records represent amounts that are expected to be invoiced in the future, so they widen the denominator without affecting charges or the invoice totals.

Charts

Budget by Project: Shows Budget, Charges, Invoices, Deferment, Financial Record, and Remaining Budget grouped by project.

Timeline: Monthly charges and cumulative remaining budget over time.

Monthly Working Time Summary: Aggregated hours and fees by month.

Budget Forecast: Projects future budget trends based on average monthly charges from the last 2 months. Green = positive forecast, orange = negative.

Data Table

The data table shows all records with the following features:

  • Event Type Filter: Filter the table by event type (Working Time, PO, Invoice, etc.) using the dropdown above the table.
  • Column Sorting: Click any column header to sort. Click again to toggle between ascending and descending order. The active sort column shows an arrow indicator.
  • Pagination: Choose page size (25, 50, 100, 250, or All rows) to control how many records are displayed at once.
  • Sheet Filter: Filter the table to show records from a specific Excel sheet/tab.
  • Search: Full-text search across all fields.
  • Comment Column: A visible column showing comment text (truncated if long; hover to see the full text). Comments come from both a dedicated Comment column and cell-level Excel comments (sticky notes).
  • Export: Export filtered data to CSV (includes Sheet and Comment columns).

Project Details

Each project card shows detailed financial information including:

  • Budget: Total Purchase Order coverage for the project
  • Total Charges: Sum of all charge types (Working Time fees + Purchase expenses + T&L expenses)
  • Closure Date: Project end date (from Closure events)
  • EAC / Final Budget: For active projects, the Estimated At Completion (forecasted remaining budget at closure). For closed projects, the actual final remaining budget.
  • Invoices: Total invoiced amounts
  • Invoice Balance: (Invoiced + Positive Financial Record) minus Total Charges
  • Remaining Budget: Current budget status (green if positive, red if negative)
  • Working Time Fees / Purchase Expenses / T&L Expenses: Breakdown by charge type
  • Deferment: Positive adds to the budget and counts as invoiced. Negative reduces the budget. Not a charge.
  • Financial Record: Positive amounts are used in the Coverage ratio. Negative reduces the budget. Not a charge.
  • Coverage: Shown next to the project name. Calculated as Charges / (Invoiced + Positive Financial Record).
  • Burndown Rate: Average monthly charge used for budget forecasting

Status Indicators

Green box: Forecasted budget is positive

Yellow box: Forecasted budget is slightly negative (only in last month and within 10% of project budget)

Red box: Forecasted budget is significantly negative (beyond 10% threshold or current budget already negative)

Filters

Use the filter section to filter data by date range, project, event type, or forecast status (Green/Yellow/Red). Quick filters are available for financial years, quarters, and months.
